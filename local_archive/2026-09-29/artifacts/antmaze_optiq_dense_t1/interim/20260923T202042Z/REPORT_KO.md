수집: 2026-09-24 05:20 KST. Dense reward + NovelD OFF. 두 온도 모두 seed0 한 개.

모든 저장 raw rollout 175개에 대해 전송SHA256, 유효 궤적/목표 도달/goal ID, dense 거리합 보상, 랜덤 시작 상태를 검증했다. 학습 알고리즘 설정은 temperature .01→1 외 동일함을 config로 대조했다.

- v1: 2M에서 위21/아래19,40/40 성공. T=.01은 위쪽39/40. T=1의 두 경로는1.5M(18/13),1.75M(22/14),2M(21/19)의 연속 평가에서 관찰된다. mu-only도 위23/아래16/실패1로 두 경로가 남는다.
- v2: 오른쪽 목표(8,0) 한 경로에37/40 성공. T=.01의36/40과 유사하며 여러 목표 유지 근거는 없다.
- v3:1.75M에서 좌상단 목표10/40 성공. 같은 예산 T=.01은0/40. 반대 방향 시도는 있지만 성공 경로는 아직 하나이다.
- v4:750k 직접정책 평가는 모두 실패지만 평가 방문0.5m 격자가84→217개, 첫 목표까지 가장 가까운 거리가13.90→6.83m로 개선됐다. 이는 학습 중 전체 coverage가 아니라 해당40회 평가 궤적의 범위다.

랜덤 시작에 따른 경로 선택과 같은 상태에서의 확률적 경로 분화를 구분해야 한다. 현재 v1은 랜덤 시작 평가에서 두 경로를 사용하는 증거이며 동일 초기상태 멀티모달성의 직접 증명은 아니다. 단일 학습seed,평가40회인 중간 결과로 최종 순위를 확정하지 않는다.

네 작업은 계속 학습 중이다. v2/v4의 과거 W&B 연결 실패는 학습 전 발생했고 검증된 동일 설정으로 offline 기록하며 학습 중이다. 동기화는 완료 후 서버 연결 복구 시 실행된다.
