# 고정 시작 AntMaze 평가: v3/v4 reward pair

같은 MuJoCo 전체 초기 상태(위치·자세·속도, XY=(0,0))에서 조건마다 40개 rollout을 실행했습니다. 각 rollout은 새 latent z를 샘플링합니다. 학습은 변경하지 않았고, 평가 전후 checkpoint hash와 policy 복원 검증을 통과했습니다.

주 결과는 conditional action σ를 제거한 **μ-only + random z**입니다. σ 포함 direct policy 평가는 보조 자료로 따로 표시했습니다. 그림의 색은 통로 선택을 나타냅니다. v3는 left/right 통로, v4는 첫 x=-4 통과 위치에서 upper/lower 통로로 분류했습니다.

## 관찰

- **v3:** 두 `100Δd` 보상 모두 성공은 G2 방향에서만 나왔고, 40회 중 거의 모두 오른쪽 통로를 택했습니다. `−d(next)` checkpoint에서는 둘 다 성공 없이 시작점 주변을 벗어나지 못했습니다. 이 고정 초기 상태에서는 v3의 두 통로 사용을 확인하지 못했습니다.
- **v4:** 세 보상 모두 40회에서 goal 도달은 없었습니다. `100Δd`는 위쪽 통로가 우세했고 아래쪽 통로는 μ-only 2회, σ 포함 5회였습니다. `100Δd−0.1`은 거의/전부 위쪽이었고, `−d(next)`는 아래쪽으로 조금 이동하거나 통로를 넘지 못했습니다. 아래쪽 rollout 몇 개가 있다는 사실은 경로 다양성의 약한 신호지만, 성공 경로 유지의 증거는 아닙니다.
- 조건부 σ를 넣으면 v3의 성공률은 증가했지만 통로 선택은 여전히 오른쪽에 집중됐습니다. 따라서 현재 평가에선 action σ가 성공률을 도울 수 있어도 v3의 반대 경로를 살렸다고 볼 수 없습니다.

## 해석 범위

각 패널의 출발 전체 상태는 동일하고 검증됐습니다. 다만 checkpoint 시점은 같지 않습니다: v3는 100k/300k, v4는 200k/250k입니다. 따라서 보상 간 수치는 현 시점 정책의 기술적 비교이며, 보상만의 인과 효과로 해석하면 안 됩니다. 표본은 seed 0의 40회 고정 시작 rollout이므로 seed 간 일반화도 주장하지 않습니다.

이번 평가는 학습 중인 프로세스나 checkpoint를 건드리지 않았습니다.
