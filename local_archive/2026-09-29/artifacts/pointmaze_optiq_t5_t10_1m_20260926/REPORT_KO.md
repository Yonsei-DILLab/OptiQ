# PointMaze OptiQ 온도 비교: 최종1M

모든 결과는 seed0, 매 행동마다 새 random z를 사용하는 μ-only 평가500회입니다. Conditional sigma는 포함하지 않습니다.

|미로|T|성공률|최다 목표 비중(성공 중)|최소 목표 비중(전체 중)|유효 목표 수|
|---|---:|---:|---:|---:|---:|
|simple|3|100.0%|38.0%|16.2%|3.81|
|simple|5|100.0%|32.8%|19.2%|3.91|
|simple|10|97.8%|26.6%|22.8%|3.99|
|medium|3|100.0%|56.2%|1.2%|2.71|
|medium|5|100.0%|39.6%|18.0%|3.79|
|medium|10|98.4%|28.3%|19.6%|3.96|
|hard|3|100.0%|53.0%|0.2%|3.70|
|hard|5|100.0%|32.0%|1.8%|5.66|
|hard|10|99.8%|15.4%|8.2%|7.82|

T10은 세 미로 모두 목표 방문 비중이 가장 고르게 나타났습니다. 단,Simple과Medium의 성공률은T3/T5의100%에서97.8%/98.4%로 조금 낮아졌고, 궤적에 우회가 더 많습니다. Hard T10은99.8% 성공과8/8목표 방문을 보였습니다.

유효 목표 수는 성공한 목표의 방문 확률 엔트로피를 지수화한 값입니다. 목표 간 균형을 요약하며, 서로 다른 길의 수나 같은 상태의 action multimodality를 직접 세는 지표가 아닙니다.

한 학습 시드의 관측이므로 일반적인 우열은 추가 시드로 확인해야 합니다. 기존T3 대조군을 재사용했고 T5/T10만 새로 학습했습니다.
