# v2 모드 복원과 엔트로피 추정 진단

완료된 Humanoid v2는 matched OptiQ보다 좋았지만, 강한 과거 기준보다
독립 최종 평가에서 4.2% 낮았다. 최종 actor의 z별 평균 변화도 매우 작았다.
이것이 수익 차이의 원인인지 확인되지 않았으므로 아래 진단은 환경 성능과 구분한다.

## 정확한 두 모드 목표

정답은 pre-tanh 평균 ±1, 표준편차 0.15, 혼합비 1/2인 분포이다.
`Q(a)=0.1 log p(a)`를 넣고 T=0.1, β=1로 정확한 Boltzmann 목표를 제공했다.
공통 `OptiQDIME.update_actor`, 16×64, conditional-mixture proposal,
conditional OT NLL, raw cost, Sinkhorn ε=0.25/100회, 256×3 actor를 사용했다.
critic 학습과 soft guard는 제외한 **projection만의 진단**이다.
seed 0·1·2, 각 3,000회 업데이트, batch=64, 평가 샘플 32,768개로 고정했다.
정답 밀도 적분과 별도 밀도 구현에 대한 Q/Jacobian 일치를 검사했다.

| 설정 | 최종 W₂² 평균 ↓ | 중앙 영역 비율 | 관찰 |
|---|---:|---:|---|
| 현재 초기 σ=.5, 상한 e | .090331 | 41.17% | σ≈1.01, z 평균 다양성 소실 |
| 초기 σ=.2, 상한 .2 | 1.031852 | 1.22% | 각 seed가 한쪽 모드로 붕괴 |
| 위 설정 + mean head 초기화 scale .1 | 1.031471 | 1.21% | 각 seed가 한쪽 모드로 붕괴 |
| 현재 σ 설정 + 초기 평균에 z 잔차 | .090573 | 41.09% | 초기 다양성도 소실 |
| σ=.2 상한 + 초기 평균에 z 잔차 | .035983 | 21.32% | 두 모드 유지, 복원은 불완전 |

정답의 중앙 영역 `|a|≤.5` 비율은 **0.13295%**이다. 마지막 설정의
pre-tanh 평균분산 기여는 약 93.57%였다. 단순 σ 상한과 head 초기화만으로는
해결되지 않았다. 마지막 설정도 정답을 충분히 복원하거나 soft improvement를
증명한 것은 아니다. W₂는 유한 샘플과 정답 성분의 결정적 quantile로 계산했다.
평균 z 잔차는 진단용 apply 함수에서만 추가했으며, 학습 코드에는 적용하지 않았다.

재현 스크립트: `scripts/diagnose_v2_bimodal.py`.
첫 세 설정이 기본 실행이며, 다음 비교는
`--variants latent_skip latent_skip_cap02 --output <별도 JSON>`으로 실행한다.
증거는 `outputs/v2_improvement/bimodal_projection.json`과
`bimodal_latent_skip_projection.json`에 있다. 각 파일은 3 seed의 모든 평가를 보존한다.

## 정확한 주변분포를 아는 엔트로피 검사

`mu(z)=z`, 조건부 σ 일정, `z~N(0,I)`이면
`u~N(0,(1+σ²)I)`이므로 tanh 정책의 실제 밀도와 엔트로피를 계산할 수 있다.
학습 없이 공통 IDAC/guard 엔트로피 함수를 사용해 M=16,64,256을 검사했다.
각 조건은 독립 샘플 4,096개이며, 실제 엔트로피는 1차원 적분을 차원별 합산했다.
이는 **합성 정책 검사**이며 완료된 Humanoid 모델의 엔트로피 값이 아니다.

| 차원 / 조건부 σ / M | 실제 H | 추정 하한 평균 | 추정 상한 평균 |
|---|---:|---:|---:|
| 17 / .5 / 16 | 10.799 | −.130 | 34.154 |
| 17 / .5 / 256 | 10.799 | 2.761 | 22.148 |
| 17 / .2 / 16 | 11.311 | −13.598 | 215.255 |
| 17 / .2 / 256 | 11.311 | −10.769 | 134.245 |

M=16, σ=.2에서는 **같은 정책끼리** 비교해도 현재
`T*(H_lower_new-H_upper_old)`의 표본평균이 −22.89다(T=.1).
따라서 이와 같은 성분 분리 상태에서는 작은 실제 개선도 승인하지 못할 수 있다.
하한/상한의 기대값 부등식과 양립하는 현상이며, 수치 오류나 부등식 위반이 아니다.
z 영향을 0으로 만든 대조군에서는 밀도 추정이 해석적 밀도와 수치 오차 내 일치했다.

`scripts/diagnose_v2_entropy_overlap.py`와
`outputs/v2_improvement/entropy_overlap_diagnostic.json`에 재현 코드·MC 오차가 있다.

## 다음 후보의 범위

σ 축소만으로 Humanoid를 다시 시작하지 않는다. 연속 latent를 매번 새로 뽑는
정책 대신, **16개 고정 latent 중 하나를 균등 선택하는 실제 유한 혼합 정책**을
별도 설정으로 검토한다. 원형의 `z~p_z`에서 p_z를 유한 분포로 명시하는 변경이다.
전체 16개 조건부 밀도를 합산하면 실제 정책 밀도가 되어 위의 finite-M
entropy-mixture 편향을 없앨 수 있다. 환경 행동은 선택한 latent로 네트워크를
한 번만 실행하면 된다. OT distillation과 Q 행동 그래디언트 배제는 유지한다.

이는 아직 구현·성능 검증된 개선안이 아니다. 정확한 밀도를 갖더라도 유한 표본
OT projection의 정책 개선이 자동 보장되지는 않는다. 이상적인 정확한 Q 및
상태별 soft-score 개선 조건과 실제 표본 승인 검사의 한계를 계속 구분해야 한다.
