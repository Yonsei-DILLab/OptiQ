# Humanoid v2: 1M 최종 확인 결과

현재 v2 구성은 추가 uniform 탐색이 없는 OptiQ 대조군보다 좋은 결과를
냈다. 그러나 이전의 더 강한 10% 탐색 OptiQ 기준은 넘지 못했다.
최종 정책은 새 평가에서 안정적으로 생존했지만 학습 도중의 일시적
성능 저하가 사라진 것은 아니다. 따라서 전체 개선 목표는 아직 미달이다.

## 고정된 평가 기준

Humanoid-v4, 학습 seed 0·1·2·3, 각 1M 환경 스텝이다. 현재 두 방법은
추가 uniform 행동 탐색을 사용하지 않았으며 일반적인 초기 5K warmup은
유지했다. 주 지표는 사전에 정한 900k–1M의 21개 평가 체크포인트 평균이다.
각 체크포인트는 stochastic 정책으로 10개 에피소드를 평가했다.
아래 ±는 네 학습 시드 평균값 사이의 표준편차이며 신뢰구간이 아니다.

| 방법 | 900k–1M 평균 ± 시드 SD | 최종 저장 정책, 새 50회 평가 ± 시드 SD |
|---|---:|---:|
| v2 checked K64 | **5362.67 ± 141.43** | **5397.09 ± 195.13** |
| 현재 OptiQ, 추가 uniform 없음 | 5051.65 ± 80.67 | 5224.07 ± 139.48 |
| 이전 OptiQ, 수집 시 10% uniform | **5676.49 ± 97.43** | **5633.18 ± 246.53** |

v2의 주 지표는 현재 대조군보다 6.2% 높고, 이전의 강한 기준보다 5.5%
낮다. 새 에피소드 평가에서도 각각 +3.3%, −4.2%다. 전체 1M 곡선의
정규화 AUC는 v2 4134.36, 현재 대조군 3328.11, 이전 기준 4237.16이다.

이전 기준은 수집 탐색과 기록된 코드 버전이 다르고 당시 작업 트리는
수정된 상태였다. 별도 강한 참고 기준으로 유지하며, 차이를 uniform
탐색 하나의 인과 효과라고 해석하지 않는다. 현재 v2와 대조군 사이에도
여러 알고리즘 요소가 다르므로 개별 요소의 효과를 분리한 실험은 아니다.

## 새 에피소드에서의 최종 정책

1M에 저장한 actor마다 환경 seed 1100000–1100049, 정책 seed
1110000–1110049를 공유해 50회씩 평가했다. 현재 8개 모델의 400회와
이전 4개 모델의 200회를 모두 포함했고 time-limit 에피소드도 제외하지
않았다. 이 검증은 정책이 계속 바뀌는 주 평가 구간과 별개다.

| 학습 seed | v2 | 현재 OptiQ | 이전 10% 탐색 OptiQ |
|---|---:|---:|---:|
| 0 | 5298.55 | 5294.33 | 5304.03 |
| 1 | 5249.13 | 5173.94 | 5670.61 |
| 2 | 5358.71 | 5054.77 | 5901.61 |
| 3 | 5681.96 | 5373.25 | 5656.48 |

v2의 200회는 모두 1000스텝에 도달했다. 현재 OptiQ는 198/200회,
이전 기준은 187/200회다. 이전 기준의 조기종료 13회는 모두 seed 0에서
나왔으며, 다른 세 시드의 보상은 여전히 강하다. 생존율만으로 전체
성능 우위를 주장할 수 없다.

현재 대조군 대비 seed 0의 평균 차이는 +4.22점으로 사실상 비슷하다.
해당 고정 모델 쌍의 에피소드 bootstrap 95% 구간도 [−7.40, 15.86]이다.
seed 1·2·3의 평균 차이는 +75.19, +303.94, +308.72점이다. 에피소드
bootstrap은 고정 모델의 평가 불확실성을 나타내며 학습 시드 불확실성은
아니다. 평가 에피소드 수가 늘어도 학습 시드는 네 개다.

## 안정성과 남은 문제

100k 이후 최근 3개 평가를 평균한 곡선의 최대 상대 하락 폭은 v2가
시드별 26.1%, 23.7%, 25.2%, 33.0%였다. 현재 OptiQ는 29.1%, 85.3%,
23.8%, 42.1%, 이전 기준은 45.0%, 42.2%, 45.3%, 42.1%였다. 이 기술적
지표에서는 v2가 대체로 덜 하락했지만 모든 비교에서 우세한 것은 아니다.

특히 v2 seed 1의 저장 정책은 같은 새 50회 평가에서 700k 5280.62점,
750k 4350.38점, 800k 3387.73점이었다. 최종 정책의 회복이 이 학습 중
불안정성을 지우지는 않는다. 같은 방문 상태에서 critic 버전에 따라
정책의 평가 순위가 바뀌었고, 새 정책이 방문한 상태에서는 평균 soft
점수가 낮아지는 진단도 있었다. 원인 후보를 좁히는 근거이지 Q 과대추정의
인과 증명은 아니다.

학습 중 평가는 해당 스텝의 업데이트 전, 체크포인트 저장은 업데이트
후다. 같은 스텝 이름이라도 정책 파라미터가 한 번의 업데이트만큼
다를 수 있다. 원래 로그와 독립 체크포인트 평가의 차이를 전부 난수
차이로 설명하지 않는다. 저장된 정책끼리의 비교는 기록된 해시로
특정한 모델의 비교이며 유효하다.

## 이론 보장의 범위

정확한 soft Q 아래에서 정확한 Boltzmann 정책 추출과 분포를 보존하는
distillation을 수행하거나, 모든 관련 상태의 실제 soft-value 개선을
확인한다면 이상적인 soft policy improvement 정리가 성립한다.
정확한 Q를 사용한다는 사실만으로 임의의 W2/NLL projection이 개선을
보장하지는 않는다.

현재 구현은 유한 후보·유한 M·신경망 projection과 replay 표본 평균
검사를 사용한다. 이 검사는 실제 모든 상태에 대한 개선 증명이 아니다.
반환값 상승, ESS, NLL 감소도 그 증명을 대신하지 않는다.
[이론 조건과 유한 근사의 한계](V2_SOFT_POLICY_IMPROVEMENT.md)를 함께
읽어야 한다.

## 재현과 보존

확인한 구성은 semi-implicit actor, scalar twin critic, 256×3 네트워크,
T=.1, β=1, 16×64 OT, conditional-mixture teacher, anchor 없음,
full conditional OT NLL, raw 제곱거리와 Sinkhorn ε=.25/100회,
IDAC M=16, 표본 기반 soft-value 필터다. 추가 Q-action gradient나 actor
entropy-gradient loss를 넣지 않았다. 실제 수식과 세부 설정은
[현재 알고리즘 설명](V2_CURRENT_ALGORITHM_KO.md)에 정리되어 있다.

8개 실행은 모두 정상 종료했고 최종 actor·critic 파일 16개와 해시를
확인했다. 900k–1M의 손실 및 Q 로그는 모두 유한했다. 최종 ESS는
5.87–7.36/64, 누적 제안 수락률은 58.0–60.1%다. 이 수치 자체가 최적
하이퍼파라미터나 정책 개선의 보증은 아니다.

학습 코드는 실행 시점 `8cb4f237aacb61113f65e693e23236f17d77f978`에서
변하지 않았다. 이후 변경은 보고·검증 코드와 문서다. 현재 브랜치는
`v2`이며 push하지 않았다. 기존 실패 구성의 재현을 보존하기 위해
launcher 기본값은 아직 바꾸지 않았다. 이번 확인 구성을 실행하려면
`OPTIQ_CONFIG=mujoco_v2_checked scripts/run_v2.sh <seed>`를 명시한다.
